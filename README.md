# 🎉 Eventoria AI — Smart All-in-One Event Planning Platform

Eventoria AI is an AI-powered event planning platform and vendor marketplace designed for organizing Weddings, Birthdays, Corporate Events, and Parties in Georgia.

---

## 🔗 Project Links
- **🌐 Interactive Live Prototype:** (https://eventoria-planning-compass.lovable.app)
- **🎨 Built with:** Lovable.dev (AI UI Builder)

---

## ✨ Key Features
- **🤖 AI Event Package Builder:** Select event type (Wedding, Birthday, Corporate), guest count, and total budget to get an instantly generated vendor package.
- **📊 Smart Budget Calculator:** Visual breakdown of costs allocated across venue, catering, photo/video, decor, and music.
- **🏪 Vendor Marketplace:** Integrated directory for local vendors with price ranges and direct booking options.
- **📱 Responsive UI:** Built with modern glassmorphism aesthetic and dark mode support.
